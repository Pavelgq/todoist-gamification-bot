# TodoistGamification Bot

**TodoistGamification** — это Telegram-бот на Python, который превращает вашу работу с задачами в Todoist игру с наградами!
Бот позволяет начислять себе “валюту” (опыт, время, золото) за выполнение задач с особыми тегами и следить за личной статистикой. Код не использует никаких фреймворков — только стандартная библиотека Python и официальные API.

## Возможности

- Подключение аккаунта Todoist c помощью OAuth
- Привязка наград (опыт, золото, время и др.) к кастомным тегам Todoist
- Автоматический подсчёт полученных наград за период (день, неделя, месяц)
- Просмотр/обновление связанных наград через Telegram
- Статистика по категориям (наградам) за выбранный период
- Асинхронная архитектура, чистый Python


## Как это работает?

1. **Добавьте бота и подключите Todoist**
2. Создайте или измените награды/метки в Telegram
3. Добавляйте соответствующий тег к нужным задачам в Todoist
4. По команде `/statistic` получите информацию о “заработанных” наградах за период

## Примеры команд

| Команда      | Описание                                                 |
| :----------- | :------------------------------------------------------- |
| `/start`     | Авторизация пользователя, подключение Todoist-аккаунта   |
| `/newreward` | Добавить новую награду и связать с тегом                 |
| `/rewards`   | Список всех ваших наград и связанных тегов               |
| `/statistic` | Статистика наград за период (день, неделя, месяц и т.д.) |

## Быстрый старт

### Требования

- Python 3.13.3
- Аккаунт в [Telegram](https://telegram.org)
- Аккаунт в [Todoist](https://todoist.com)
- Переменные окружения (см. ниже)


### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/your-username/todoist-gamification-bot.git
cd todoist-gamification-bot
```

2. Установите зависимости (если используются сторонние библиотеки):
```bash
pip install -r requirements.txt
```

3. Настройте переменные окружения:
```
TELEGRAM_BOT_TOKEN=ваш_телеграм_токен
TODOIST_CLIENT_ID=ваш_todoist_client_id
TODOIST_CLIENT_SECRET=ваш_todoist_client_secret
DATABASE_URL=ваша_бд
TODOIST_REDIRECT_URI=адрес_для_oauth_перенаправления
```

4. Запустите бота:
```bash
python src/bot.py
```

## Пример использования

- Добавьте Telegram-бота себе в чат
- Авторизуйтесь через /start
- Создайте награды: например, "Опыт" для тега `статья`, "Золото" для тега `покупка`
- В Todoist добавляйте нужные теги к задачам
- Закрывайте задачи — бот добавит награды за каждый выполненный тег
- Получайте статистику
